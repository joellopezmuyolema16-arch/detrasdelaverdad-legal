Política de Privacidad

Esta aplicación ("Detrás de la Verdad Automation") accede únicamente a los datos necesarios para publicar contenido en la cuenta de TikTok autorizada (@detrasdelaverdad_oficial) mediante la API de TikTok.

No se recopila, almacena ni comparte información personal de terceros. Los datos de autenticación (tokens de acceso) se usan exclusivamente para conectar con la API de TikTok y no se comparten con ningún tercero.

El titular de la cuenta puede revocar el acceso de la aplicación en cualquier momento desde la configuración de su cuenta de TikTok.
